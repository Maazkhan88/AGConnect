# Contributing

Work milestone-by-milestone. Add schemas and server authorization before UI flows. Keep strict TypeScript, validate external input with Zod, use explicit DTO selections, preserve tenant scope, and avoid raw CSS/JavaScript from stored data.

Before review run `pnpm typecheck`, `pnpm lint`, `pnpm test`, and `pnpm build`. Update documentation, migrations, seed strategy, and the checklist whenever behavior changes.
